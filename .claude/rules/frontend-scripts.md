# Frontend Scripts

- `src/scripts/*.js` are small vanilla-JS modules (no UI framework) each imported via a `<script>` tag in the one component that owns that behavior: mobile nav, header scroll state, program mega-menu, hero countdown, stats count-up, the ajakan card (`ajakan.js`), FAQ accordion (shared by `Faq` and `FaqHome`), fade-in-on-scroll, jejak gallery lightbox, share buttons, legal-page TOC scrollspy. The `/jejak/` feed script is the one exception, inline in the page because it is coupled to that page's markup contract.
- **`Ketentuan.astro` is an accordion with no script at all**, and that is deliberate rather than an oversight. It uses native `<details>`/`<summary>` instead of reusing `faq.js`, because with scripting off a scripted accordion renders headings whose bodies can never be opened — a degradation for FAQ answers, and a failure for terms a visitor is told to read before donating. The chevron rotates through `group-open:rotate-180`, and the default disclosure triangle needs suppressing in two places (`list-none` for Chrome and Firefox, `[&::-webkit-details-marker]:hidden` for Safari). Reach for `<details>` over `faq.js` whenever the content still has to work with JavaScript off.
