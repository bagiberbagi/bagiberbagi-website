# Astro Migration (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the existing single-page bagiberbagi.id donation site (a site-builder export in `bagiberbagi.dc.html`/`content.js`/`support.js`/`image-slot.js`) to a plain Astro + Tailwind project, same content and structure, styling tidied up, no dependency on the proprietary builder runtime.

**Architecture:** Static Astro site (`output: 'static'`, no adapter). Page content split into one `.astro` component per original section. Small structured data (programs, features, steps, impacts, faqs, footer nav, socials) lives in a single typed `src/consts.ts`. Long-form legal text (privacy/terms/transparency) lives in an Astro Content Collection (`src/content/legal/*.md`) since each is a Phase-2 standalone-page candidate. Pure calculation/formatting logic (Rupiah formatting, WhatsApp link building) lives in `src/lib/format.ts`, unit-tested with `bun test`. Client-side behavior (mobile nav, scrollspy, fade-in-on-scroll, activity ticker, stats count-up, FAQ accordion, donation calculator) is small vanilla-JS modules in `src/scripts/`, each imported via a `<script>` tag in the component that owns it — no UI framework, no Alpine.

**Tech Stack:** Astro (static output), Tailwind CSS (`@astrojs/tailwind`), TypeScript (strict), bun (package manager + test runner), Astro Content Collections (Zod schema).

## Global Constraints

- Package manager is bun for every command in this plan (`bun ...` / `bunx ...`), per project decision — do not substitute npm/pnpm/yarn.
- `astro.config.mjs` must keep `output: 'static'` — no SSR adapter (no deploy target chosen yet).
- No UI framework (React/Vue/Svelte/Alpine) — all interactivity is vanilla JS in `src/scripts/`.
- Visual/content parity with the current live site is required for every section; styling may be tidied (Tailwind utilities replacing inline styles) but copy, structure, and section order must match `legacy/bagiberbagi.dc.html` exactly, with the two exceptions already agreed: the 3 documentation photos become static placeholders (no upload/crop widget), and the "Bangun Dampak Bersama" cards keep their hardcoded copy (they were never in `content.js`).
- Legacy builder files (`bagiberbagi.dc.html`, `content.js`, `image-slot.js`, `support.js`) move to `legacy/` and are never imported by the new Astro code — they exist for reference only.
- `plan.md`, `faq.md`, `kebijakan.md`, `syarat.md` stay untouched at the repo root — Phase 2 backlog, out of scope for this plan.
- Tailwind custom breakpoint `nav: '860px'` replaces the JS `window.innerWidth < 860` check from the original — desktop/mobile nav switching must be pure CSS.
- Color tokens: `brand.yellow #FFD900`, `brand.blue #1D46B9`, `brand.orange #F4791D`, `ink #0F172A`, `muted #64748B`, `border #EEF0F3`. Font: `Plus Jakarta Sans` (Google Fonts, already linked in the legacy `<head>`).

```ts
// src/lib/format.ts
export function formatRupiah(amount: number): string {
  return 'Rp ' + amount.toLocaleString('id-ID');
}

export function calcTotal(pax: number): number {
  return pax * 25000;
}

export function buildWaLink(waNumber: string, text?: string): string {
  if (!text) return `https://wa.me/${waNumber}`;
  return `https://wa.me/${waNumber}?text=${encodeURIComponent(text)}`;
}

export function buildDonationMessage(program: string, pax: number, totalFormatted: string): string {
  return `Halo, saya ingin donasi program "${program}" untuk ${pax} pax (Total: ${totalFormatted}).`;
}

export function formatProgramOptionLabel(opt: { label: string; disabled: boolean }): string {
  return opt.disabled ? `${opt.label} (Segera Hadir)` : opt.label;
}
```

```js
import { STAT_TARGETS } from '../consts';

const section = document.getElementById('stats-section');
const danaEl = document.getElementById('stat-dana');
const donaturEl = document.getElementById('stat-donatur');
const berbagiEl = document.getElementById('stat-berbagi');
const areaEl = document.getElementById('stat-area');

let started = false;

function animate() {
  const duration = 1800;
  const start = performance.now();

  function tick(now) {
    const t = Math.min(1, (now - start) / duration);
    const eased = 1 - Math.pow(1 - t, 3);

    danaEl.textContent = 'Rp ' + (STAT_TARGETS.dana * eased).toFixed(1) + 'Jt';
    donaturEl.textContent = Math.round(STAT_TARGETS.donatur * eased).toLocaleString('id-ID');
    berbagiEl.textContent = Math.round(STAT_TARGETS.berbagi * eased).toLocaleString('id-ID');
    areaEl.textContent = Math.round(STAT_TARGETS.area * eased).toLocaleString('id-ID');

    if (t < 1) requestAnimationFrame(tick);
  }

  requestAnimationFrame(tick);
}

if (section && danaEl && donaturEl && berbagiEl && areaEl) {
  const observer = new IntersectionObserver(
    (entries) => {
      if (entries[0].isIntersecting && !started) {
        started = true;
        animate();
      }
    },
    { threshold: 0.3 }
  );
  observer.observe(section);
}
```

- [ ] **Step 1: Write `src/scripts/faq-accordion.js`**

```js
const items = document.querySelectorAll('.faq-item');

let openIndex = 0;

function render() {
  items.forEach((item, i) => {
    const answer = item.querySelector('.faq-answer');
    const chevron = item.querySelector('.faq-chevron');
    const isOpen = i === openIndex;
    answer.classList.toggle('hidden', !isOpen);
    chevron.style.transform = isOpen ? 'rotate(180deg)' : 'rotate(0deg)';
  });
}

items.forEach((item, i) => {
  item.addEventListener('click', () => {
    openIndex = openIndex === i ? -1 : i;
    render();
  });
});

render();
```
